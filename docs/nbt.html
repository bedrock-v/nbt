max_depth is how deeply lists and compounds may nest. Decoding recurses once per level, so without it a few hundred kilobytes of nested lists from a client overflow the stack.

fn encode #

fn encode(root RootTag, opts Options) []u8

encode writes a root tag. In the fixed size forms a string longer than max_fixed_string can't be written and encode panics on one rather than write NBT that misreads everything after it. encode_checked returns that as an error instead.

enum Encoding #

enum Encoding {
	// network_little_endian is what Bedrock sends over the network: ints, longs
	// and lengths are varints.
	network_little_endian
	// little_endian is what Bedrock writes to disk (LevelDB worlds) and hashes
	// block states over: every number has a fixed size.
	little_endian
	// big_endian is the fixed size form Java Edition uses and some Bedrock data
	// files are distributed in.
	big_endian
}

Encoding is the form NBT is written in.
